Paste your adventure text below or load a file. The formatter will validate the format and show you any issues. Note: Section colons are optional - use "Section 1", "Section 1:", or "## SECTION 1", all work! Markdown headers with anchors like "## SECTION 1 {#section-1}" and markdown choice links like "[45](#section-45)" are also supported. Item Detection: The formatter automatically detects items/loot using 12+ detection patterns including: action verbs ("you find a sword"), containers ("chest contains gems"), locations ("there is a key"), quantities ("3 potions"), stat modifiers ("+2 dagger"), and more!
