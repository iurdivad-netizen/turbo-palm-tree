Introduction - Standalone Format

This adventure demonstrates all 6 supported section number formats
working together in a single adventure. Each section uses a different
format to show the parser can handle any of them!

Formats demonstrated:
- Section 0: Standalone number
- Section 1: Section X: format
- Section 2: [X] bracket format
- Section 3: **X** Markdown bold format
- Section 4: X. period format
- Section 5: (X) parentheses format
