This adventure demonstrates all 6 supported section number formats
working together in a single adventure. The parser is smart enough
to recognize any of these formats!

0

Standalone number format (most common in real imports)

[1]

Bracketed format (common in some gamebooks)

**2**

Markdown bold format (for Markdown authors)

3.

Number with period at start of line (PDF format)

(4)

Parentheses format

This shows how versatile the parser is. You can mix and match formats,
and the parser will understand them all!
